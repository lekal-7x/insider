- 👑 **ผู้คุมเกม** รู้คำลับ ตอบได้แค่ ใช่/ไม่ใช่/ไม่รู้
- 🕵️ **ตัวแฝง** รู้คำลับแบบลับๆ คอยชี้นำให้ทุกคนทายถูก
